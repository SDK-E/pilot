# Accessibility

Pilot's interface is built with accessibility as a first-class concern.

## Keyboard Navigation

- All interactive elements are focusable via Tab
- Focus indicators use `--ring` color with visible outline
- Escape closes modals, dialogs, and dropdowns
- Focus returns to trigger element after modal close
- Sidebar navigation uses arrow keys

## Focus Management

- Focus is visible on all interactive elements
- Focus order follows visual order
- Focus traps in modals and dialogs
- `suppressHydrationWarning` on `<html>` prevents focus shift on hydration

## Reduced Motion

- `disableTransitionOnChange` on ThemeProvider prevents jarring transitions
- Animations respect `prefers-reduced-motion` via CSS
- Skeleton loading states avoid pulse animations on demand

## Contrast

- All text meets WCAG AA contrast ratios (4.5:1 for normal text, 3:1 for large)
- `--ring` color provides visible focus indicator on all themes
- `--destructive` color used for destructive actions with confirmation

## Touch Targets

- All interactive elements meet 44x44px minimum touch target
- Button padding ensures adequate touch area

## Zoom

- Layout is responsive at 200% zoom (320px minimum viewport width)
- Text scales without breaking layout
- Sidebar collapses at narrow viewports

## Language & Direction

- `lang="en"` set on `<html>` in layout.tsx
- RTL support prepared via logical CSS properties
- i18n keys used for all user-facing text (when available)
